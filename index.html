Menarian's HTML and CSS Cheat Sheet

This page will list different HTML and CSS properties, elements and selectors which might be useful to remember or ones which I have struggles with to remember.

HTML Semantics
Tag Description
<a> Creates a clickable link. using href will allow providing a URL. Can also point to local files
<article> It represents a self-contained composition in a document, page, application, or site, which is intended to be independently distributable or reusable
<aside> Meant for content that's only indirectly related to the document's main content
<details> Creates a disclosure widget in which information is only visible when toggled on. Kind of like a dropdown

<summary> creates the label, "Example" in this case
<figcaption> Used in conjunction with <figure> to give the figure an accessible name
<figure> Represents self-contained content, potentially with an optional caption
<footer> Represents a footer for its nearest ancestor sectioning content or sectioning root element
<form> Creates a field which a user can fill with information. But it also needs a method, name and label. The empty forms can be pre-filled with :empty.

<header> Typically used for banners or an introduction to a certain topic.
<main> Represents the main content in the body of the document. The content is directly related to the document's topic and expands upon it.
<mark> Marks the text as if using a text marker. Like this
<nav> Represents part of the document meant to guide the user across it by providing links to either itself or other documents.
<section> Generic section of the document without a special use case. Best to use heading in sections.
<summary> Only used for <details> as seen further up.
<time> Represents a specific period of time, often used with datetime to translate it into machine-readable format for better search engine results.
